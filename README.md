# Event Timer

A beautiful, interactive meeting timer web application with ambient background music and visual design.

## Features

- **Meeting Timer**: Display and manage meeting time with a large, easy-to-read timer display
- **Background Music**: 11 curated background music tracks to enhance focus and atmosphere
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Modern UI**: Clean, dark-themed interface with professional styling
- **Visual Overlay**: Timer overlaid on a background image for an immersive experience

## Project Structure

```
event-timer/
├── index.html          # Main HTML interface
├── tracks/             # Background music library (11 MP3 files)
├── README.md           # This file
└── TEAM_EVAL_RULES_2.png
```

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. The timer interface will load with the dark theme and background image

## Music Tracks

The `tracks/` directory contains 11 background music files:
- background_music_01.mp3 through background_music_11.mp3

These tracks are designed to provide ambient sound during meetings and events.

## Technical Details

- **Language**: HTML5, CSS3, and JavaScript
- **No Dependencies**: Runs entirely in the browser with no external libraries required
- **Responsive**: Uses modern CSS features like `clamp()` for fluid sizing

## Usage

Open `index.html` in any modern web browser. The application provides an intuitive interface for:
- Starting, pausing, and resetting the timer
- Selecting background music tracks
- Full-screen viewing for presentations

## Browser Compatibility

Works with all modern browsers that support:
- HTML5 Audio
- CSS3 Flexbox and Transforms
- ES6 JavaScript
